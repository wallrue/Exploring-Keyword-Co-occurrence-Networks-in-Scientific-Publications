# Project 3: Exploring Keyword Co-occurrence Networks in Scientific Publications

**Course:** IE6400 Foundations Data Analytics Engineering  
**Student:** Le Minh Tuong (ID: 003151597)

### Overview
This project analyzes how research keywords appear together in academic publications. I used a dataset of keywords and built a weighted network to find which topics are the most "important" or "central" in the field.

### Repository Contents
* `data/keywords_data.csv`: Source dataset of articles and keyword columns.
* `analysis.py`: Python implementation using Pandas, NetworkX, and Matplotlib.
* `report.md`: Detailed interpretation of the network results.
